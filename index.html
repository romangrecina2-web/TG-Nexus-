Ассистент

Уровень рассуждений теперь можно менять прямо в верхней панели чата. Поддержка зависит от модели; при ошибке 400 выберите «Авто».

Разрешения ИИ

Работает через OpenRouter Web Search. Модель сама решает, когда искать. Поиск может оплачиваться отдельно по тарифам OpenRouter/поискового провайдера. Запросы и контекст передаются провайдеру поиска.
Разработка и песочницаМультиагентный режим, JavaScript и интернет
Вспомогательные агенты анализируют задачу параллельно и передают замечания основной модели, которая собирает итоговый ответ. Модели берутся из сохранённого списка и используют текущий адрес API. Одну модель можно использовать в нескольких ролях. От 1 до 20, включая основную модель. Остальные ИИ работают как специалисты; запросы отправляются группами максимум по 4. Каждый дополнительный агент расходует токены и может тарифицироваться провайдером. Код запускается в отдельном изолированном iframe без доступа к файлам, localStorage, sessionStorage и API-ключу. Это не полноценный сервер и не Python-среда. Только HTTPS через fetch к публичным доменам с поддержкой CORS. Cookies, localhost, IP-адреса, XMLHttpRequest и WebSocket заблокированы. До 10 запросов и 2 МБ данных на один запуск. CORS-ограничения сайтов всё равно действуют. От 1 секунды до 3600 секунд (1 час). По умолчанию 60 секунд. По истечении времени выполнение принудительно останавливается.

Память

Эти факты отправляются модели в каждом чате. Добавить факт можно здесь или фразой «запомни: …» в чате.
    Не записывайте сюда пароли и личные данные: на бесплатных серверах запросы могут сохраняться.

    Контекст и экономия

    Когда накопится столько, ИИ допишет к своему следующему ответу скрытый пересказ (отдельного запроса нет, бесплатные лимиты не тратятся). Старые сообщения перестанут отправляться, вместо них уходит пересказ. Сам чат на экране не меняется. Пересказ можно прочитать и поправить кнопкой «📝 Пересказ» вверху.
    Остаток аккаунта OpenRouter обычному ключу не отдаёт (нужен ключ управления), поэтому введите баланс со страницы openrouter.ai/settings/credits один раз. Дальше оболочка сама вычитает расход этого ключа. После пополнения введите баланс заново. Расходы других ключей аккаунта не учитываются. Пока баланс не введён, проверка не работает. Это только ваша страховка: решение всё равно принимает OpenRouter. Для моделей с «:free» проверка не нужна.
